Биологийн Нөөцийг Хамгаалах Төвийн өмч. Зөвхөн төвийн судлаачдын хэрэглээнд.

## 1. GitHub Pages дээр байршуулж линк авах (нэг удаа, 10 минут)

1. **github.com** руу орж бүртгүүлнэ (имэйл, нууц үг). Имэйлээ баталгаажуулна.
2. Баруун дээд буланд **+** → **New repository**.
   - Repository name: `brcc` (эсвэл дурын нэр, зайгүй)
   - **Public** сонгоно
   - **Create repository** дарна.
3. Нээгдсэн хуудсанд **uploading an existing file** гэсэн холбоос дарна (эсвэл **Add file → Upload files**).
4. Дараах файлуудыг бүгдийг нь чирж оруулна: `index.html`, `sw.js`, `manifest.json`, бүх `.png` файлууд.
   Доор **Commit changes** дарна.
5. Репогийн дээд цэснээс **Settings** → зүүн талаас **Pages**.
   - Source: **Deploy from a branch**
   - Branch: **main**, хавтас **/ (root)** → **Save**.
6. 1–3 минут хүлээгээд тэр хуудсаа дахин ачаалахад дээр нь линк гарна:
   `https://ТАНЫ-НЭР.github.io/brcc/`
   Энэ бол аппын линк. Судлаачдад яг үүнийг явуулна.

**Засвар, шинэчлэлт:** шинэ `index.html` (болон бусад өөрчлөгдсөн файл) авбал репо дотроо **Add file → Upload files** гээд ижил нэртэй файлыг дахин оруулна — хуучныг нь орлоно. 1–2 минутын дараа бүх утсанд шинэчлэгдэнэ (аппаа хаагаад дахин нээхэд).

## 2. Утсанд суулгах (судлаач бүр)

**iPhone (Safari):** линкийг Safari-аар нээнэ → доод талын **Хуваалцах** (дөрвөлжин + сум) → **Нүүр дэлгэцэд нэмэх / Add to Home Screen** → **Add**.

**Android (Chrome):** линкийг Chrome-оор нээнэ → баруун дээд **⋮** → **Нүүр дэлгэцэд нэмэх / Add to Home screen** (эсвэл **Install app**) → **Add**.

Дараа нь нүүр дэлгэц дээрх **BRCC** дүрсээр нээнэ. Нэг удаа сүлжээтэй нээсний дараа сүлжээгүй газар бүрэн ажиллана.

Анхаар: аппыг **заавал нүүр дэлгэцэд нэмсэн дүрсээр нээж хэрэглэнэ.** Хөтчийн таб дээр ажиллуулж байгаад хөтчийн түүх, өгөгдлийг цэвэрлэвэл бүртгэл алдагдана.

## 3. Google Sheets холбох (нэг удаа, 15 минут) — бүх судлаачийн өгөгдөл нэг хүснэгтэд

1. **sheets.google.com** дээр шинэ хүснэгт үүсгэнэ, нэр өгнө (ж: `BRCC field data`).
2. Дээд цэснээс **Extensions → Apps Script**.
3. Нээгдсэн код бичих цонхны доторх бүх зүйлийг устгаад `google-apps-script.gs` файлын кодыг бүхэлд нь буулгана. **Хадгална** (💾).
4. Баруун дээд **Deploy → New deployment**.
   - Type (араа дүрс ⚙): **Web app**
   - Description: `BRCC`
   - Execute as: **Me**
   - Who has access: **Anyone** (энэ заавал — утаснууд нэвтрэлтгүй бичих учраас)
   - **Deploy** → зөвшөөрөл асуувал **Authorize access** → өөрийн Google аккаунтаа сонгоно → "Google hasn't verified this app" гарвал **Advanced → Go to BRCC (unsafe)** → **Allow**.
5. Гарч ирсэн **Web app URL**-ийг хуулна (`https://script.google.com/macros/s/…/exec` хэлбэртэй).
6. Аппын **⚙ Тохиргоо → Google Sheets холбоос** талбарт тэр холбоосыг буулгана.
7. Судлаач бүрийн утсан дээр мөн энэ холбоосыг тохиргоонд оруулна (нэг удаа). Дараа нь ажиглалт хадгалах бүрт, сүлжээ байвал шууд, байхгүй бол сүлжээ орох үед автоматаар хүснэгтэд мөр нэмэгдэнэ.

Хүснэгтэд **Data** (ажиглалт бүр нэг мөр) болон **Surveys** (сесс бүр нэг мөр) гэсэн хоёр хуудас автоматаар үүснэ. Засварласан ажиглалт ижил ID-аар шинэчлэгдэнэ. Судлаачид хүснэгтийг харж чадахгүй — та өөрөө хэнтэй хуваалцахаа шийднэ.

Скриптийг дараа өөрчилбөл **Deploy → Manage deployments → ✎ → Version: New version → Deploy** гэж дахин байршуулна (холбоос өөрчлөгдөхгүй).

## 4. Аппын бүтэц, хэрэглээ

**Судалгаа** (хавтас, ж: Uvs airport) → **Явалт** (огноо) → **Ажиглалт**: **VP** (цэгэн) эсвэл **LT** (шугаман замнал) → шувуу/амьтан бүрийн бичлэг. Мөн судалгаа бүрт **Тэмдэглэл** (хээрийн дэвтэр, зурагтай).

- Судалгаа үүсгэхэд зүйлийн нэрний хэл (Монгол / Англи / Латин) болон салхин станц (wind farm) эсэхийг сонгоно. Wind farm бол VP формд турбины хоёр талбар нэмэгдэнэ.
- **VP:** VP №, ажиглагч, огноо, төлөвлөсөн хугацаа (анхдагч 3 цаг) бичээд **Ажиглалт эхлэх**. Хугацаа дуусахад дуу + чичиргээ. Утасны сэрүүлгээ давхар тавьж хамгаална.
- **LT:** **Замнал эхлэх** дарахад GPS автоматаар зам бичнэ (дэлгэц асаалттай, апп нээлттэй байх). Ажиглалт бүрт ажиглагчийн солбицол автоматаар орно; зай + азимут бичихэд амьтны солбицол тооцоологдоно. **Замнал дуусгах** дарахад дууссан цэг, урт автоматаар. **KMZ татах** — Google Earth-д нээнэ.
- **⚡ Хурдан бүртгэх:** шувуу гарч ирмэгц нэг дарна — цаг, секундомер (VP), солбицол (LT) шууд авагдаж шар карт үүснэ. Хэд ч дарж болно (зэрэг нисвэл). Дараа нь картыг нээж бөглөөд **Хадгалах**.
- **Хадгалаад дараагийнх:** зүйл, амьдрах орчин, цаг агаар өмнөхөөс хуулбарлагдана; өөрчлөгдсөнийг л засна.
- Бичиж байгаа бүх зүйл үсэг бүр дарах бүрт утсанд хадгалагдана. Дуудлага ирсэн, цэнэг дууссан, апп хаагдсан ч дахин нээхэд яг тэр карт байна.
- **Ажиглалт дуусгах** → сесс түгжигдэнэ, тойм гарна. Засах бол **Засахаар нээх**.
- **Устгах** → 30 хоног **Хогийн сав**-д хадгалагдана, сэргээж болно.
- **Excel татах:** сесс, явалт, судалгаа, эсвэл бүх өгөгдөл. Нэг мөр = нэг ажиглалт, бүх талбар багана, зүйлийн нэр MN/EN/Latin гурван баганад. Утсан дээр "Хуваалцах" цонх гарвал Telegram, имэйлээр шууд явуулна.
- **Тохиргоо:** MN/EN хэл, шөнийн горим, Google Sheets холбоос, **Нөөцлөх** (бүх өгөгдлийг нэг файлд татах) / **Сэргээх**.

**Зөвлөмж:** явалт бүрийн төгсгөлд Excel эсвэл нөөц файл татаж хадгалах. Утас солих бол нөөц файлаа шинэ утсандаа "Нөөцөөс сэргээх"-ээр оруулна.

## 5. Хязгаарлалт (веб апп учраас)

- LT замнал бичих үед апп нээлттэй, дэлгэц асаалттай байх ёстой (апп дэлгэцийг унтраахгүй байлгахыг оролдоно). Халаасанд хийвэл бичилт зогсоно — дахин нээхэд **Бичилтийг үргэлжлүүлэх** дарна.
- VP сэрүүлэг апп нээлттэй үед найдвартай; дэлгэц унтарсан үед iPhone дээр дуугарахгүй байж болзошгүй. Утасны сэрүүлгийг давхар тавина.
- Өгөгдөл утас бүрт тусдаа. Нэгтгэхийн тулд Google Sheets холбох эсвэл Excel файлаа илгээнэ.

Зүйлийн жагсаалт: шувуу 507, хөхтөн 138, мөлхөгч 23, хоёр нутагтан 6. Жагсаалтад байхгүй зүйлийг апп дотроос **+ Шинэ зүйл нэмэх**-ээр нэмнэ.
